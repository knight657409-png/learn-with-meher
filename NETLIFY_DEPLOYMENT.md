## Deploy with GitHub and Netlify
1. Extract this ZIP on your phone using Files or an archive app.
2. In GitHub, create a new repository named `learn-with-meher`.
3. Upload the **contents** of the extracted folder (not the ZIP and not the parent folder). `package.json`, `index.html`, `src`, and `public` must be at the repository root.
4. In Netlify, choose Add new site → Import an existing project → GitHub, then select the repository.
5. Use build command `npm run build` and publish directory `dist`. Leave Base directory blank.
6. Deploy and wait for the Published status.

The Netlify build configuration is also recorded in `netlify.toml` and uses Node.js 22.

## Domain / SEO note
No custom domain has been assumed. After Netlify creates your actual site URL, update the canonical URL and sitemap to that exact URL if you want to add them. The site does not currently advertise the unconfirmed `learnwithmeher.com` domain.
